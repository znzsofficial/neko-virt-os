# Settings — 扩充计划

最后更新：2026-07-24

## 文案原则（macOS 式）

- 分区标题 + 控件标签即可，**不写说明段 / hint / 状态散文**（VR 等实验项仅 badge + 开关，无操作说明）  
- 危险操作靠 **确认对话框**，不靠页面上的警告段落  
- 网络 / 存储等「探测结果」只出现在对应分区，**关于页不重复**
